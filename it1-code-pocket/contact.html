お問い合わせ

問題内容の誤り、表示不具合、改善要望などがありましたら、運営者までご連絡ください。

お問い合わせはGoogleフォームで受け付けています。返信が必要な場合は、フォーム内にメールアドレスをご入力ください。

送信前に プライバシーポリシー をご確認ください。

お問い合わせフォームを開く

お問い合わせの前に

こんなご連絡が助かります

  • 問題や解説の誤り … 正解が違う、解説の計算が合わない、コードが動かない など
  • 表示の不具合 … レイアウトが崩れる、ボタンが反応しない、シミュレーターが動かない など
  • 改善のご要望 … 扱ってほしいテーマ、追加してほしい機能 など
  • 掲載内容の利用について … 授業や塾などでの利用のご相談

誤りのご指摘をいただく際は、ページ名と問題番号（例：「集計する処理の読み方／例題4」）を添えていただけると、確認が早くなり助かります。

ご返信について

個人で運営しているため、返信までにお時間をいただく場合があります。内容によっては返信を差し上げられないこともありますので、あらかじめご了承ください。

返信をご希望の場合は、フォーム内にメールアドレスをご入力ください。入力がない場合、こちらから連絡する手段がありません。

お答えできない内容

申し訳ありませんが、次のご質問にはお答えできません。

  • 共通テスト本番の出題内容や範囲についての予想
  • 進路相談、志望校の選択に関するご相談
  • 当サイト以外の教材や問題集についてのご質問

当サイトの問題や解説に関するご質問であれば、可能な範囲でお答えします。

個人情報の取り扱い

フォームでお預かりした情報は、お問い合わせへの対応のみに使用し、それ以外の目的では利用しません。詳しくは プライバシーポリシー をご確認ください。運営者については 運営者情報 に記載しています。
