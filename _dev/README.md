# _dev（開発用・本番では使わないファイル）

テーマの動作には使われないファイルの置き場です。本番サーバーへアップロードする必要はありません。
（誤ってアップロードされても `.htaccess` で外部からは見えないようにしています）

| フォルダ | 中身 |
|---|---|
| `docs/` | 開発メモ・入力テンプレート（`dev_intro.md` は git 管理外） |
| `source-images/` | 書き出し前の元画像。Web用の画像は `assets/images/` に置く |
| `server-root/` | サイトのドキュメントルートに置くファイルの控え（`ads.txt` / `robots.txt`）。テーマ内に置いても公開URLには反映されないため、変更時はサーバーのルートへ配置する |
